# 🌦️ Previsão do Tempo com IA

App web que consulta a previsão do tempo de uma localidade e usa inteligência artificial para sugerir roupas adequadas ao clima do momento.

## ✨ Funcionalidades

- Busca a previsão do tempo em tempo real para a cidade informada
- Sugestão de roupas gerada por IA com base nas condições climáticas
- Interface simples e responsiva

## 🛠️ Tecnologias utilizadas

- HTML, CSS e JavaScript
- [OpenWeatherMap API](https://openweathermap.org/api) — dados de previsão do tempo
- [Groq API](https://groq.com/) — geração das sugestões de roupas com IA
- dotenv — gerenciamento seguro das chaves de API
